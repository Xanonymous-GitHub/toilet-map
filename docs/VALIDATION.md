# 全國覆蓋版驗證紀錄

驗證日期：2026-10-11（Asia/Taipei）。資料與測試報告的機器時間保留 UTC。本版整合日韓全國 OSM 及地方官方來源，提供 181 個城市與周邊快捷範圍。

## 已通過

- `bun install --frozen-lockfile` 與 `uv sync --locked`：鎖檔可重複安裝。
- `bun run verify`：Bun／Vite 正式建置、Biome recommended lint（warnings 視為失敗）、Ruff lint 與 format check、TypeScript strict（含獨立 Service Worker 型別），以及 **22 項 Bun 原生測試**通過。
- API 逐一查詢全部 181 城市，確認有實際候選、筆數對帳、國家一致與 bounds 內座標。首爾 5,952 筆候選的完整分頁沒有漏頁或重複 ID；以首爾 region 查詢釜山 bbox 也可取得該國其他城市資料。
- 測試涵蓋非首都及離島定位、開放時間與跨午夜、韓國 `25:00`、星期／假日條件保留未知、資格與設施未知、導航格式，以及拒絕重複／循環／截斷／混用版本或 bounds 的分頁。
- 非法參數、過大範圍、加上 fetch padding 後的範圍上限、HEAD／405、PWA MIME／快取及完整 OSM 原始／衍生匯出均通過。
- `bun run deps:check`：15 項直接套件／工具版本均與官方最新穩定版一致，見 `dependency-versions.json`；MapLibre 為 6.14.0。GitHub Actions 版本也向官方 release 查證並固定。
- 兩個 Python 匯入器重跑，以及沒有 ignored 原始檔的獨立乾淨目錄，都產生完全相同的 dataset bytes、45,867 筆紀錄、來源、coverage 與資料版本。公開下載 metadata、SHA-256 與欄位稽核隨研究目錄保存。
- Chromium **34 項完整操作檢查**通過，包含相模原、倉敷、大阪、札幌、金浦、釜山、濟州切換；釜山 GPS 正確選擇釜山；國家切換記住上次城市；拖曳超出初始範圍發出新的 bbox 請求。
- 桌面 1440×1000／手機 viewport 390×844，確認地圖及實際聚合標記、詳細資訊、導航、收藏、定位權限、篩選、來源、搜尋、Service Worker、離線清單、手機捲動與安裝說明。手動縮放會停止 watcher，晚到定位不會覆蓋使用者選擇，損壞收藏可復原。
- 原生 dialog 的鍵盤檢查確認背景控制項不會取得焦點，符合 modal 的 inert 行為。沒有未處理的 JavaScript 或地圖 Worker 載入錯誤。
- 最後的底圖警示修正另以 **2 項定向瀏覽器檢查**通過：實際阻斷圖磚請求仍可使用廁所清單；解除阻斷後取得 25 個經 CA 驗證的真實 OSM 圖磚，舊警示會清除。

機器可讀結果：`browser-report.json`、`map-recovery-report.json`。完整操作程式為 `scripts/browser-qa.py`；截圖保存於 ignored `test-results/`。Vite 仍提示地圖套件造成較大的 JavaScript chunk，主程式 gzip 約 378 KB，另有地圖 Worker 約 144 KB gzip；尚未量測低速行動網路效能。CI workflow 已配置，並在本地執行相同的必要關卡；目前 Sites 的來源 Git 服務不會自行執行 GitHub Actions。

## 測試環境與實機範圍

代理環境的 Chromium 未信任當次代理 CA。使用一次性 Playwright 來源橋接器，由 Python 保留代理與 CA 驗證取得公開圖磚／字型，再交給測試頁面；未修改永久 TLS 信任設定，也未關閉瀏覽器 TLS 驗證。離線階段停用橋接器並設定 browser offline，API 失敗後由 IndexedDB 恢復最近下載的相同範圍。離線及刻意阻斷圖磚產生的網路錯誤為預期行為。

瀏覽器使用模擬座標及手機 viewport。尚未在真實 iPhone／Android 確認 GPS 精度、主畫面安裝與地圖 App 交接。導航 URL 格式已驗證；OS 是否開啟 App 取決於安裝情況與預設設定。

已瀏覽的最近範圍可離線重開；底圖不預下載、不加入 Service Worker 離線快取。資料更新由匯入器執行後重新部署，本版沒有每日背景排程。
