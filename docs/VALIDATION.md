驗證日期：2026-10-11 UTC。目標為私人測試版；資料涵蓋首爾與東京江東區／新宿探勘範圍。

- `npm run build`：Vite 正式前端、Worker ESM 打包、TypeScript 嚴格檢查完成。Vite 提醒地圖套件造成較大 JavaScript chunk；本版 gzip 約 370 KB，尚未進行低速行動網路效能量測。
- `npm test`：13 項，8 項核心邏輯、5 項 API。涵蓋韓國 25:00、跨午夜、邊界關閉時間、複雜時段未知、資格與設施未知、導航座標及編碼、座標範圍、來源唯一 ID、首爾完整分頁、400／404 行為、PWA 資產與 OSM 衍生資料匯出。
- Chromium 瀏覽器：18 項操作檢查。桌面 1440×1000、手機 viewport 390×844，包含地圖載入、詳細資訊、Google／Kakao 步行 URL、收藏、模擬 GPS 切換首爾、開放篩選、來源說明、鍵盤焦點、地點搜尋、Service Worker、離線重載、無水平溢出、拒絕定位提示、手機詳細資訊捲動、安裝說明與無未處理程式錯誤。
- 目視檢查桌面、手機與詳細資訊截圖；加大資訊字體、提高文字對比與控制項大小。

機器可讀結果：`browser-report.json`。瀏覽器測試與截圖程式：`scripts/browser-qa.py`；截圖寫入忽略的 `test-results/`。

## 測試環境與實機範圍

代理環境的 Chromium 未信任當次代理 CA。使用一次性 Playwright 來源橋接器，由 Python 保留代理及 CA 驗證取得公開圖磚／字型，再交給測試頁面；沒有修改使用者的永久 TLS 信任設定，沒有關閉瀏覽器 TLS 驗證。離線階段停用橋接器並將瀏覽器設為 offline，API 失敗後從 IndexedDB 恢復 4,455 筆首爾資料。離線期間的底圖／API 網路錯誤為預期行為。

瀏覽器使用模擬座標及手機 viewport。尚未在真實 iPhone／Android 裝置確認 GPS 精度、主畫面安裝，以及 Apple／Google／NAVER App 的實際交接。導航 URL 格式已驗證；OS 是否開啟 App 取決於安裝情況與預設設定。

已瀏覽城市的資料可離線重開；底圖不預下載、不加入 Service Worker 離線快取。資料更新由匯入器執行後重新部署，本版沒有每日背景排程。
