## 範圍查詢與執行方式

- 城市選單是快速前往的預設矩形查詢範圍。相鄰城市範圍會重疊，筆數不能加總，也不是行政市界的設施數。
- API 的 `region` 選擇國家與預設 bounds；提供 `bbox` 時搜尋該國家全部點位，不限於紀錄的最近城市分組。拖曳超出已載入區域後會取消舊請求，以 450 ms debounce 載入新範圍。
- 資料按國家與 0.25° 空間格 gzip 壓縮；Worker 只解壓交集格，LRU 上限 8,000 筆；前端每頁最多 1,000 筆，沒有全國預載。過大縮放範圍引導放大地圖。
- 每個城市的最近下載範圍保存到 IndexedDB。離線可重開這個範圍的清單與 App shell；沒有離線底圖，也不把部分下載說成整座城市。
- GPS 用來選附近城市與移動地圖。API 請求包含地圖範圍；沒有獨立的 GPS 或軌跡寫入介面。
- 保留來源 ID 與原始 OSM JSON。`/api/v1/osm-export?country=JP`／`KR` 提供該國完整原始及衍生資料的串流下載。
