# 狀態保存與分享網址

瀏覽器保存目前城市與國家、各國最後選擇的城市、地圖中心／縮放／方向／傾斜、搜尋、全部篩選、外觀、側欄收合、進階篩選、已展開清單筆數、目前面板與廁所，以及最近成功查看的廁所。清單、設定、廁所詳細頁與說明視窗的捲動位置也會保存。

重新開啟沒有畫面參數的首頁會恢復上次使用狀態。開啟分享網址則優先使用網址中的畫面，包含預設值，避免混入接收者自己的舊搜尋或篩選。既有 `?region=busan` 城市網址仍可使用；`?toilet=<id>` 可直接解析廁所、選擇所在城市並移動到該點。

## 分享與瀏覽歷程

「分享目前畫面」會優先使用裝置分享功能，否則複製網址。剪貼簿不可用時提供可選取的網址；取消分享不會改變底下的畫面。地圖、手機面板、廁所詳細頁和說明視窗均有分享入口；網址本身也可直接複製。

分享格式為 `/#v=1&region=busan&c=129.075%2C35.18%2C16%2C0%2C0&theme=dark&sidebar=1&panel=map`。畫面使用 fragment 保存，瀏覽器不會把 `#` 後的內容傳給主機，因此大型收藏清單不會增加伺服器請求網址長度。舊 query 格式會轉為相同的 fragment 格式，其他 query 參數保留。

| 參數 | 內容 |
| --- | --- |
| `v`、`region` | 狀態版本、城市；國家由城市決定 |
| `c` | 經度、緯度、縮放、方向、傾斜 |
| `q`、`f` | 搜尋文字與啟用的篩選 |
| `toilet` | 目前開啟的廁所 ID |
| `theme`、`sidebar`、`more` | 外觀、側欄、進階篩選 |
| `panel` | 地圖、清單、設定、來源或安裝說明 |
| `limit`、`scroll` | 清單展開筆數與捲動位置 |
| `ss`、`ds`、`ms` | 設定、詳細資訊與說明視窗的捲動位置 |
| `saved` | 僅在收藏篩選啟用時，加入該清單的公開廁所 ID |

城市、篩選、廁所與面板切換建立瀏覽紀錄；地圖移動結束、搜尋輸入與捲動使用 replace，避免每個按鍵或動畫幀都新增一頁。上一頁／下一頁與手動開啟 fragment 會還原畫面。地圖經緯度保存至小數第五位，約一公尺；方向、縮放與傾斜保存至小數第二位。

## 個人收藏與廁所快取

收藏保存在自己的瀏覽器。一般分享不附上個人收藏；分享收藏篩選畫面時，接收者會看見「分享的收藏」，可以查看那些公開設施，自己的收藏不會被匯入或覆蓋。關閉再啟用收藏篩選會回到自己的收藏。

版本化狀態使用 localStorage；舊的城市、外觀與側欄偏好仍可讀取。IndexedDB 從版本 1 升級到版本 2，保留既有地區快取並增加已查看廁所的快取。廁所不在目前載入範圍時，透過既有的 `/api/v1/toilets/:id` 直接查詢並驗證結果；取消或較晚返回的舊請求不會覆蓋新選擇。404 不會繼續顯示已失效的快取。

## 實際還原範圍

分享連結的接收者需要有權存取該部署網址。私人 Sites 預覽維持原有權限；部署到可公開存取的 Netlify／Vercel 網址後，他人即可使用相同連結功能，不需要新增服務端頁面路由。

不同螢幕會採用合適的桌面／手機排版，捲動位置也會受到實際內容高度限制。跟隨系統模式依接收者裝置外觀呈現；開放狀態依接收時的時間與資料計算。即時 GPS 標記、定位權限、原生分享／選單／安裝視窗、toast 與載入動畫不當作可還原的畫面狀態。瀏覽器禁止儲存時，分享網址仍可還原，無參數重開則無法保證恢復偏好。
